==🔴Comandos e o que ele faz:==

- adduser (nome): ==🟢==adiciona usuário
- adduser (nome) sudo: torna o usuário como sudo (necessario digitar "sudo" no inicio de comandos)
- deluser (nome) sudo: tira o sudo do user
- deluser (nome): remove o user do sistema
- cat /etc/passwd: mostra todos os users
- nano /etc/sudoers: abre um editor na qual poderá editar perm de users
- cat /var/log/auth.log ([precisa baixar um app pra esse comando]): mostra todos os logs, da pra ver oq outros users fizeram
