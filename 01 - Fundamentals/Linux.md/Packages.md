# What i learned?
**Answer:** The sources.list file contains all repository packages available in Linux to install apps and updates. The main file is located in /etc/apt/sources.list. 

**Commands:** 
- sudo apt upgrade: Update all system's programs and packages. 
- apt search ([keyword]): Search repositories for packages matching the specified keyword
- sudo apt install ([program name]): Install the program.
- sudo apt remove ([program name]): Remove the application.
- sudo dpkg -i ([file name]): Installs packages ending with .deb  (Debian)
