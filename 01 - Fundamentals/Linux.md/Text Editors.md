

1- Nano (terminal): Run nano ([filename]) to create or edit a file.
    Commands for nano: 
     - CTRL + K: cut a line
     - CTRL + U: to uncut the line
     - CTRL + X: Exit

2- Vi (terminal):  Run vi ([filename]) to create or edit a file.
     Commands for vi:
      - Type "i" to start editing.
      - Press "d" twice to delete a line.
      - Press esc and type / to search for the text.
      - To exit without saving, press esc then type :q!
      - To save changes press esc and type :wq
 3- Gedit (graphical interface): Without Sudo, run gedit ([filename]), to create or edit a file.
