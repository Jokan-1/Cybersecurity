**Answer**: How to manage services in Linux.

# Commands:
- sudo service ([service-name]) start: Start the specified service.
- sudo service ssh start: Start the SSH server daemon to allow secure terminal access (port 22).
- sudo service ([service-name]) stop: Stop a running service.
- sudo service ([service-name]) restart: Restart the service to apply configuration changes.
- sudo service apache2 start: Run the webserver apache.
- firefox localhost: Open localhost in firefox.
- sudo update-rc.d ([service-name]) enable: Enable running the service on system's boot.
- sudo update-rc.d ([service-name]) disable: Disable running the service on system boot.
