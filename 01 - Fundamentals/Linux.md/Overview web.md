
# Protocolo HTTP

- **Basicamente funciona através de requisições e respostas, vindas do cliente e do servidor , respectivamente**. 

# Estrutura HTTP

- **É composta por um body e um header**
  
- **Suporta vários métodos, tais métodos são conhecidos como GET, POST, HEAD, PUT , DELETE, OPTIONS.** 
  
- **Os mais utilizados são o GET e o POST, sendo o GET usado para requisitar recursos do servidor e o POST para enviar dados, geralmente em formulários.

# Códigos de Status

- **A cada requisição , o web server retornará um código, tais elas:
     - `200:` Ok.
     - `301:` O recurso foi movido.
     - `403:` Permissão negada.
     - `404:` Recurso não encontrado
     - `500:` Erro interno do servidor
